# Discord-Bot
NCG Discord Bot

A Discord bot + web panel for Rust server / team management, with full Rust+
companion integration.

## Rust+ integration

Users link their Rust+ (Steam) account through a self-serve login page, then pair
their server and smart devices in game. The bot connects over Rust+ and exposes
the companion-app features in Discord and in-game team chat.

### Setup

1. Copy `.env.example` to `.env` and fill in `DISCORD_TOKEN`, `DISCORD_CLIENT_ID`,
   `DISCORD_GUILD_ID`. Set `PUBLIC_URL` to the public URL of the web panel (used
   for the `/pair` login link); it defaults to `http://localhost:PORT`.
2. `npm install`
3. `npm run deploy:commands` to register slash commands.
4. `npm start`

### Linking an account (the "Rust+ Login" flow)

1. A user runs `/pair` in Discord and opens their private login link.
2. They sign in with Steam on the Rust+ login page. The bot registers FCM/Expo
   push credentials and stores the Steam-linked token for that user.
3. In game they open **Rust+** and pair their server / smart devices. The bot
   receives the pairing notifications over FCM and connects automatically.

If the browser popup can't capture the auth token (Rust+ login security), the
login page also accepts a `rustplus.config.json` generated by
`npx @liamcottle/rustplus.js fcm-register` (manual fallback).

### Features

| # | Feature | Where |
|---|---------|-------|
| 1 | Team chat commands (`!time`, `!pop`, `!online`, `!leader`, `!device`, `!turret`, `!craft`, `!recycle`, …) | in-game team chat |
| 2 | Server push notifications (pairing, smart alarm, player death) | Discord channels |
| 3 | Smart device pairing with names / groups | `/device` |
| 4 | Server event alerts (heli / cargo / chinook / crate / explosion) | `/rustservers channel type:events` |
| 5 | Vending machine item search | `/vending` |
| 6 | Player status tracking (BattleMetrics) | `/track` |
| 7 | CCTV camera surveillance (cameras / drones / turrets) | `/camera` + camera station web page |
| 8 | Rust Labs data (craft / recycle / decay / despawn) | `/rustlabs` |
| 9 | Team leader transfer | `/leader`, `!leader` |
| 10 | Team member deaths on the map | `/deaths map:true` |
| 11 | Team member statistics (play / AFK time) | `/teamstats` |
| 12 | Turret interference calculator | `/turret`, `!turret` |

Configure where each notification type is posted with
`/rustservers channel type:<events|alarms|chat|deaths|tracker|default>`.

### Security

`rustplus.config.json`, `data/credentials.json` and `data/rustplus.json` contain
Steam-linked auth tokens and server pairing tokens. They are gitignored — never
commit them. Rotate any token that has been committed.
